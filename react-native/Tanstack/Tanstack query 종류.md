### **Core API**

1. **QueryClient**: 서버 상태를 관리하는 핵심 객체입니다. 쿼리, 캐시, 뮤테이션 등을 관리하기 위한 모든 설정과 상태를 가지고 있습니다.
2. **QueryCache**: 모든 쿼리 캐시 데이터를 저장하고 관리합니다.
3. **MutationCache**: 모든 뮤테이션 캐시 데이터를 저장하고 관리합니다.
4. **QueryObserver**: 쿼리를 관찰하고, 쿼리가 업데이트될 때마다 컴포넌트에 알리는 역할을 합니다.
5. **InfiniteQueryObserver**: 무한 스크롤과 같은 기능을 구현할 때 사용되며, 페이지 단위로 데이터를 로드하는 쿼리를 관찰합니다.
6. **QueriesObserver**: 여러 쿼리를 동시에 관찰하고 관리할 수 있도록 도와줍니다.
7. **focusManager**: 애플리케이션의 포커스 상태를 관리하여, 사용자가 앱으로 돌아왔을 때 데이터가 새로고침되도록 도와줍니다.
8. **onlineManager**: 네트워크 상태를 관리하여, 오프라인/온라인 전환 시에 데이터를 다시 가져오도록 설정할 수 있습니다.
9. **notifyManager**: 쿼리나 뮤테이션이 업데이트될 때 콜백을 호출하여 컴포넌트에 상태 변화를 알리는 역할을 합니다.

### **React Hooks API**

1. **useQuery**: 서버에서 데이터를 가져오기 위해 사용하는 기본적인 훅입니다. 데이터를 캐시하고, 자동으로 새로고침하며, 상태 관리가 편리합니다.
2. **useQueries**: 여러 개의 쿼리를 동시에 사용하고 관리할 때 사용하는 훅입니다. 여러 요청을 한 번에 실행하고, 각 쿼리의 상태를 관리할 수 있습니다.
3. **useInfiniteQuery**: 페이지 단위로 데이터를 가져오거나 무한 스크롤을 구현할 때 사용하는 훅입니다. 스크롤 위치나 특정 조건을 기반으로 데이터를 추가로 가져올 수 있습니다.
4. **useMutation**: 서버에 데이터를 보내거나 서버 상태를 변경할 때 사용하는 훅입니다. POST, PUT, DELETE와 같은 요청을 수행하며, 이를 통해 데이터 변동 작업을 관리합니다.
5. **useIsFetching**: 현재 어떤 쿼리가 데이터를 가져오고 있는지 확인하기 위해 사용됩니다. 로딩 인디케이터와 같은 UI 요소를 표시할 때 유용합니다.
6. **useIsMutating**: 현재 어떤 뮤테이션이 진행 중인지 확인하기 위해 사용됩니다.
7. **useMutationState**: 특정 뮤테이션의 상태를 확인하고 관리할 때 사용하는 훅입니다.
8. **useSuspenseQuery**: React의 `Suspense`와 함께 사용하여 데이터가 로딩 중일 때 UI를 쉽게 제어할 수 있도록 돕는 훅입니다.
9. **useSuspenseInfiniteQuery**: `Suspense`와 함께 무한 스크롤 데이터를 관리하기 위해 사용합니다.
10. **useSuspenseQueries**: 여러 개의 쿼리를 `Suspense`로 관리할 때 사용하는 훅입니다.
11. **QueryClientProvider**: `QueryClient`를 React 애플리케이션에 제공하는 컨텍스트 프로바이더입니다. 애플리케이션의 최상위 컴포넌트에서 사용합니다.
12. **useQueryClient**: 현재 컨텍스트의 `QueryClient`를 쉽게 접근하고 사용할 수 있게 해주는 훅입니다.
13. **queryOptions**: 쿼리의 기본 옵션들을 설정할 때 사용하는 유틸리티입니다.

### **기타 API**

1. **infiniteQueryOptions**: 무한 스크롤 쿼리의 기본 옵션을 설정하기 위한 유틸리티입니다.
2. **usePrefetchQuery**: 데이터를 미리 가져오기 위한 쿼리 훅입니다. 이를 통해 사용자가 페이지를 이동하기 전에 데이터를 미리 캐시에 저장할 수 있습니다.
3. **usePrefetchInfiniteQuery**: 무한 스크롤 데이터의 사전 로드를 관리하기 위해 사용됩니다.
4. **QueryErrorResetBoundary**: 오류가 발생했을 때 오류를 감지하고, 오류 상태를 재설정할 수 있도록 돕는 컴포넌트입니다.
5. **useQueryErrorResetBoundary**: 쿼리의 오류 상태를 관리하고 재설정하는 기능을 제공하는 훅입니다.
6. **hydration**: 서버 측에서 가져온 데이터를 클라이언트로 "수화(hydration)"하여 React Query 캐시에 저장하는 데 사용됩니다.

각각의 API는 특정 상황에서 서버와의 데이터를 효율적으로 관리하고 애플리케이션의 성능을 최적화하기 위해 사용됩니다. 필요한 경우에 맞는 API를 선택하여 사용하시면, 더욱 편리하고 강력한 데이터 페칭 경험을 얻을 수 있습니다.
